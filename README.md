# Space Track

**How Multimodal Agents Perceive, Update, and Act in Changing 3D Worlds**

Space Track is an interactive benchmark for multimodal agents: five walkable first-person 3D worlds that change as the agent acts, 59 tasks (15 of them counterfactual controls), and one shared observation and action interface.

- Website: https://zk-yuan.github.io/spacetrack/
- Paper (PDF): [paper.pdf](paper.pdf)

Every task runs in the browser and can also be played by a person; open a world from the website and press Play.
